# Little Wonders · Everyday Series web app

Static site: no server, no build step. Open `index.html`, or upload the whole folder to GitHub Pages / Netlify (all paths are relative).

- `index.html` home: sections Flashcard Packs, Games, Stories & Reading, Lessons (+ drop-down menus).
- `viewer.html?book=<id>` lesson viewer: pages as slides, games/video slots in between. ← → keys, swipe, thumbnails, full screen. `#N` in the URL jumps to step N.
- Data lives in `js/data.js` (generated by `/workspace/everyday-series/web-app-src/build_app.py`). No fetch, so the viewer works from file://.

## Offline (file://) notes
Everything now runs by double-clicking `index.html` (Chrome/Edge, no server). Tested in headless Chrome on file:// (Oct 20, 2026): home, lesson viewers, Four Corners, Land Neighbours, Story Library, Animal Memory, Match the pet, Save Sam, Jack texts, Chem Word Lab.
The fixes are applied by `web-app-src/offline_fix.py`, which `build_app.py` runs after copying the games, so a rebuild reproduces them:
- **Four Corners** (embedded copy only; Jarvis's own folders are untouched): the Vite ES-module build is re-bundled with esbuild into one classic script `assets/fc-bundle.js` (no `type=module`, no chunk preloads). Chrome blocks `fetch()` of file:// URLs and won't let file:// images into WebGL, so `assets/fc-offline.js` (only active on file://) serves every model/texture from `offline/<path>.js` script packs as Blobs. Over http(s) the normal files are used. The copied `.git` folder is no longer included.
- **Land Neighbours**: ES modules bundled into `js/app.bundle.js` (classic script). The JSON data and the WebGL/canvas images (relief map, China skins) are inlined in `js/offline-data.js`, so there is no fetch and no canvas taint.
- **Story Library**: the white-background cut-outs (kids, librarian, Hopper) are precomputed as PNGs in `assets/cut/` (same algorithm as the JS) and listed in `cutouts.js`, so there are no canvas pixel reads and no "tainted canvas" error.
- Fonts from Google Fonts need internet; without it the games fall back to system fonts.
- esbuild lives in `web-app-src/tools/node_modules` (installed with npm on first use).
- Tests: `web-app-src/tests/site-test.mjs <base-url> <tag>` (all pages) and `tests/memtest.mjs` (Animal Memory).

## Hosting
- Every HTML page gets `<meta name="robots" content="noindex, nofollow">`; the site root has `robots.txt` (Disallow all) and `.nojekyll` (all added by `offline_fix.py`).
- Hosted unlisted on GitHub Pages: repo `littlewondersesl-max/lw-everyday-lvofgqp` (public, not linked anywhere), site https://littlewondersesl-max.github.io/lw-everyday-lvofgqp/ . To update: rebuild, copy `web-app/` into a clone of that repo, commit, push to `main`. No file is over 100 MB (largest is a ~69 MB PPTX).
